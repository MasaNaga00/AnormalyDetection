# 引き継ぎ用ファイル一覧（新チャットに添付するもの）

2026-10-01 更新（horizon マージ・カテゴリ別運用を反映）。

## 必ず添付

### 検知エンジン（既存）
- `cusum_monitor.py` … **必須**。信号B/Cが `binom_sf` を流用している
- `earlylife_baseline.py` … **必須**。CUSUM側が import する

### 本体
- `settings.py` … **共通の設定はすべてここ**
- `config_loader.py` … `--cat` の解釈とカテゴリ設定への切り替え
- `categories/_テンプレート.py`（＋実運用中のカテゴリファイル）… カテゴリごとの差分設定
- `state_logic.py` … 閾値検出
- `state_logic_cusum.py` … CUSUM（シャドー実行用に維持。前処理を本線が流用）
- `signal_b_peer.py` … 信号B
- `signal_c_dist.py` … 信号C（`inspect()` 同梱）
- `reporting_horizon.py` … 販社の報告遅れ（horizon）
- `panel_maturity.py` … スナップショット保存・熟成カーブ
- `unified_inbox.py` … 3検出器の統合＋台帳
- `run_month.py` … 月次実行（1カテゴリ）
- `run_all.py` … 全カテゴリの一括実行

### ドキュメント
- `引き継ぎ資料_マルチ信号トラック編.md` … **全状態・設計判断。まずこれ**
- `はじめに_使い方ガイド.md` … 運用手順の入口
- `本番運用ドキュメント.md` … 立ち上げ・月次・定期見直し・トラブル対応
- `数理解説_閾値信号BC.md` … 計算手法の全導出

## 操作点を決める段階なら追加

- `tune_c_alpha.py` / `tune_b_minoe.py` … 実測スイープ（`tb.confirm` / `tb.nb_profile` あり）
- `inject_power.py` … ラベルが無くても検出力を測る
- `check_rank.py` … 過去例が上位N件に入るか
- `check_panel.py` … パネルの投入前チェック
- `検出時期確認/trace_detection.py` … 機種×部番を指定し、各検出器の初検出月と鳴らない理由を月ごとに再現

## 症状の調査なら追加

- `check_settings.py` … 実際に読まれている設定の確認
- `diagnose_signal_c.py` … 信号Cで「なぜ出ない」を段階ごとに切り分け
- `diag_b_row.py` … 信号Bの行がどう計算されたか
- `diag_fleet_growth.py` … 信号Cの分母が効いているか
- 該当月の `出力/<カテゴリ>/YYYYMM/実行記録.txt` … その回の設定・入力

## 報告遅れ対応を触るなら追加

- `販社報告遅れ対応_メモ.md` … 設計
- `verify_lag.py` … 検証（4項目）
- `lag_triangle.py` … 元データ（1行1修理）が手に入ったとき用（未使用）

## シミュレーションを再現するなら追加

- `gen_sim_panel.py` … データ生成
- `panel_初回.csv` / `panel_翌月.csv` … パネル
- `台帳_空.xlsx` / `台帳_記入例.xlsx` / `台帳テンプレート_統合版.xlsx`
- `categories/サンプル.py` … カテゴリ実行の見本（panel_翌月＋台帳_記入例）
- `仕込み一覧.csv` … **答え合わせ用。体感する前に開かない**
- `test_unified.py` / `test_suppress.py` … 統合と抑制の検証
- `gen_peer_panel.py` / `gen_dist_panel.py` … 信号B/C単体の検証用

## 動作確認（ファイルを揃えたら最初に）

```bash
python settings.py                                   # 共通設定の一覧表示
python gen_sim_panel.py                              # データ生成
python run_month.py panel_初回.csv 台帳_空.xlsx        # 1回目 → 11件
python run_month.py panel_翌月.csv 台帳_記入例.xlsx    # 2回目 → 7件（消し込み確認）
python run_month.py --cat サンプル --no-snapshot      # カテゴリ実行 → 7件
python verify_lag.py                                 # 報告遅れ対応（「すべて期待どおり」）
python test_suppress.py                              # 検出器別抑制の検証
```

`出力/YYYYMM/`（カテゴリ実行は `出力/サンプル/YYYYMM/`）にファイルが出て、
2回目で件数が減れば結線は正常。
